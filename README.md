# بيور ترجمة

مشروع Android Studio حقيقي (Java) - نافذة عائمة (فقاعة) تترجم وتبيض اي نص إنكليزي تشوفه الشاشة تلقائياً بدون ما تضغط عليها، باستخدام:
- **OCR**: ML Kit Text Recognition (يشتغل على الجهاز بالكامل، مجاني، بدون مفتاح API)
- **ترجمة**: ML Kit Translate (تنزل موديل اللغة أول مرة بس، وبعدها تشتغل offline)

## كيف تبنيه (APK حقيقي)
1. حمّل **Android Studio** (مجاني).
2. افتح هذا المجلد كمشروع (Open an existing project).
3. خله يخلص Gradle Sync لحاله (يحتاج نت أول مرة عشان يحمل المكتبات).
4. Build > Build Bundle(s)/APK(s) > Build APK(s).
5. تنزل الـ APK من app/build/outputs/apk/debug/ وتنصبه بموبايلك.

## ملاحظة مهمة عن Sketchware Pro
Sketchware Pro ما يفتح مشاريع Android Studio مباشرة (نظام ملفاته مختلف تماماً عن Gradle). اللي تكدر تسويه:
- تستورد مكتبتين ML Kit نفسهم بـ Sketchware Pro (Library Manager > Add Library من Maven)، وتعيد كتابة كود OverlayService بلوكات/Java Code مباشر داخل Sketchware نفسه (فيه خيار "Add Java Code" يقبل كود مثل هذا تقريباً حرفياً).
- الأسهل والأضمن: تبنيه مباشرة بـ Android Studio زي فوق، وترفع الـ APK الجاهز على GitHub - أسرع بكثير وأقل أخطاء.

## أشياء لازم تعرفها (صراحة)
- **OCR عربي**: ML Kit Text Recognition الافتراضي يقرا حروف لاتينية (انكليزي) بس. اذا النص الأصلي بالمانهوا عربي، لازم مكتبة OCR ثانية (Tesseract). كودت المشروع افتراضياً English → Arabic لأن هذا الاستخدام الأغلب بالمانهوا.
- **أول تشغيل يحتاج نت** عشان يحمل موديل الترجمة (مرة وحدة بس، بعدها يشتغل بدون نت).
- **صلاحيتين لازم توافق عليهم يدوياً** أول مرة: النافذة العائمة (Overlay) + تسجيل الشاشة (Screen Capture) - أندرويد ما يسمح لأي تطبيق ياخذهم تلقائي بدون موافقتك، حتى لو "بيور" نفسها.
- **الفقاعة**: تسحبها لأي مكان، تضغط عليها تطلع خيارين (إخفاء / إيقاف). لو ضغطت إخفاء، تختفي بنفس مكانها بالضبط، وتحتاج 5 ضغطات بنفس المكان خلال ~3.5 ثانية عشان ترجع تظهر - أي ضغطة عرضية وحدة أو ثنتين وإنت تلعب ما تحرك مكانها ولا تظهرها.
- الترجمة تشتغل تلقائياً كل ثانيتين ونص من أول ما توافق على الصلاحيات - ما تحتاج تضغط على الفقاعة عشانها تشتغل.
